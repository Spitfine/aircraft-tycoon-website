    body:
      en: >-
        ## A design is a connected system


        Changing a major component can affect several outcomes at once. Engine
        choice matters, but so do construction method, wing configuration and
        airframe structure. The useful question is not “which component is
        best?” but “which combination best supports this aircraft’s intended
        role?”
      pt: >-
        ## Um design é um sistema interligado


        Alterar um componente importante pode afetar vários resultados ao mesmo
        tempo. O motor importa, mas também importam o método de construção, a
        configuração de asa e a estrutura. A pergunta útil não é «qual é o
        melhor componente?», mas sim «que combinação serve melhor a função
        pretendida para esta aeronave?».

        be confirmed.
